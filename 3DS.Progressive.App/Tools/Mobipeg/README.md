# Motor MOFLEX: Mobipeg v2.3

Definitive Randomizer ejecuta `ffmpeg.exe` y `ffprobe.exe` como procesos separados. No requiere instalación del sistema ni conexión para editar vídeos. No contiene vídeos de juegos.

Origen oficial: https://github.com/quatric/mobipeg/releases/tag/v2.3
Binario Windows x86_64: https://github.com/quatric/mobipeg/releases/download/v2.3/mobipeg-windows-x86_64.zip
SHA-256 del ZIP: `9f15c9f7359be362ae8704ee0a0d6fc8046162311eefe471f3466ebf4530831b`

Fuentes correspondientes: https://github.com/quatric/mobipeg/releases/download/v2.3/mobipeg-v2.3-source.tar.gz
SHA-256 de las fuentes: `532cafe82cb0e3136a2677eaa82f615eb2bcafab2439c264bde2ccb22dc1965c`
El archivo de fuentes se incluye en esta carpeta en el candidato local. Instrucciones de compilación: README-upstream.md y documentación contenida en las fuentes. El codificador utiliza el fork x264 de https://github.com/quatric/x264.

Créditos: quatric (Mobipeg), FFmpeg y sus colaboradores, VideoLAN/x264 y sus colaboradores. Esta compilación habilita GPL y libx264; consultar LICENSE.md, COPYING.GPLv2 y demás licencias incluidas. Los ejecutables se distribuyen sin modificaciones. Los avisos y términos del motor son independientes de los de Definitive Randomizer.

Para preparar un checkout nuevo, ejecutar `Preparar-Mobipeg.ps1`. Los binarios y archivos comprimidos están excluidos de Git. No se descarga software al abrir la aplicación.
